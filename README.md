# Portafolio profesional — Efraín González

Portafolio web de **Efraín González**, **Senior .NET / Software Engineer**, con más de 20 años de experiencia en desarrollo de software empresarial.

Este repositorio contiene el código del portafolio público: [portafolio-efraingon.vercel.app](https://portafolio-efraingon.vercel.app/).

## Posicionamiento

- C# y .NET Core
- ASP.NET Core / ASP.NET MVC
- APIs REST documentadas con Swagger/OpenAPI
- Microsoft SQL Server, T-SQL, procedimientos almacenados y optimización de consultas
- Power BI, ETL y generación de reportes
- Integraciones de software y controles de acceso

## Proyectos destacados

- [SysPedido](https://github.com/Efraingon/SysPedido/) — API C#/.NET 9 con ASP.NET Core, Swagger, SQL Server, SignalR y arquitectura multi-tenant.
- [ProyectYZR](https://github.com/Efraingon/ProyectYZR/) — aplicación web para control de proyectos y actividades; [demo pública](https://proyectyrz.vercel.app/).
- Sistemas y evoluciones profesionales relacionados con VUCE Costa Rica, SISTRAN, conciliación bancaria, inventario, firma electrónica, ERP y dashboards Power BI.

## Stack del portafolio

| Área | Tecnologías |
| :--- | :--- |
| Framework | Next.js 15 (App Router), React 19 |
| Lenguaje | TypeScript (strict mode) |
| Estilos | Tailwind CSS, PostCSS, clsx, tailwind-merge |
| Estado y datos | Zustand, TanStack Query |
| API | Next.js API Routes |
| Despliegue | Vercel |

## Funcionalidades

- Presentación de proyectos técnicos y experiencia profesional.
- Filtros por categoría para la selección de proyectos.
- Calculadora interactiva de alcance y estimación.
- Formulario de contacto y acceso directo a correo y LinkedIn.
- Diseño adaptable, accesible y optimizado para dispositivos móviles.

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación queda disponible en [http://localhost:3000](http://localhost:3000).

Para generar una build de producción:

```bash
npm run build
npm run start
```
